# Programming Skills Portfolio - Assessment 1

## Overview

This repository contains three C++ coding challenges completed as part of the CodeLab II module.

The purpose of this assessment is to demonstrate my understanding of programming concepts covered throughout the module, including functions, vectors, file handling and object-oriented programming (OOP).

Each challenge is organised into a separate folder containing the C++ source code and any required text files.

## Challenge 1 – CO2 Calculator

The CO2 Calculator estimates the carbon dioxide emissions produced during a car journey based on the distance travelled and the type of fuel used.

**Features:**
- Enter the journey distance in miles.
- Choose between petrol and diesel.
- Calculate estimated CO2 emissions using the provided emission factors.
- Display the results in kilograms.

**C++ concepts used:** Functions, variables, conditional statements, user input and mathematical calculations.

## Challenge 2 – Alexa Joke Generator

The Alexa Joke Generator is a simple program that selects and displays random jokes from a text file.

**Features:**
- Reads jokes from `randomJokes.txt`.
- Stores the jokes using a vector.
- Selects a random joke.
- Displays the joke setup first.
- Waits for the user to press Enter before revealing the punchline.
- Accepts the command "Alexa, tell me a joke" with or without the comma.
- Allows users to request more jokes or quit the program.

**C++ concepts used:** Functions, vectors, file handling, strings, loops and random number generation.

## Challenge 3 – Book Manager

The Book Manager is a simple library management system that reads and manages book information from a text file.

**Features:**
- Reads book information from `bookData.txt`.
- Uses a Book class to store book details.
- Displays all books in the library.
- Allows users to view individual books using their ID.
- Allows users to borrow and return books.
- Updates and saves the borrowed status of each book.

**C++ concepts used:** Classes, objects, constructors, vectors, file handling, functions and conditional statements.

## How to Run

1. Download or clone the repository.
2. Open the project in Visual Studio Code or another C++ development environment.
3. Make sure a C++ compiler is installed.
4. Open the folder of the challenge you want to run.
5. Compile and run the `main.cpp` file.
6. For Challenges 2 and 3, ensure the required `.txt` file is in the program's working directory.
